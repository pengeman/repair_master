# 页面显示风格规范（统一规范）

> 目的：全项目页面显示风格统一。本文档为**强制约定**，新增/修改页面必须遵守。
> 公共样式已统一引入，页面内禁止重复定义内联样式（特殊场景除外，需注明原因）。

---

## 1. 样式引用（自动生效，无需页面处理）

- 公共样式表：`/ruoyi/css/ry-ui-ext.css`
- 已在 `include.html` 的 `header` 片段中统一引入，**所有页面自动加载**，页面内不要再写 `<link>` 引入。
- 项目扩展样式类（只读框、状态标签、图片预览等）定义见 `ry-ui-ext.css`。
- RuoYi 内置样式类（`detail-*`、`tag-ok`、`tag-err` 等）见 `ruoyi/css/ry-ui.css`。

---

## 2. 浏览/详情页（只读表单）

**布局**：与编辑页完全一致的 `form-horizontal` 结构，每个字段一行：`标签 + 只读输入框`。

**标准写法**：

```html
<body class="white-bg">
    <div class="wrapper wrapper-content animated fadeInRight ibox-content">
        <form class="form-horizontal m" id="form-xxx-detail" th:object="${xxx}">
            <input name="id" th:field="*{id}" type="hidden">
            <div class="col-xs-12">
                <div class="form-group">
                    <label class="col-sm-3 control-label">字段名：</label>
                    <div class="col-sm-8">
                        <input th:value="*{field}" class="form-control" type="text" readonly>
                    </div>
                </div>
            </div>
            <!-- ... 其余字段 ... -->
        </form>
    </div>
    <th:block th:include="include :: footer" />
</body>
```

**规则**：

| 项目 | 约定 |
|---|---|
| 页面标题 | `header('浏览XXX')`，XXX 为业务名 |
| 输入框 | `class="form-control"` + `readonly`（灰底只读态由公共样式统一提供） |
| 标签 | `label class="col-sm-3 control-label"`，文字以 `：` 结尾（全角冒号） |
| 日期字段 | `th:value="${#dates.format(xxx.date, 'yyyy-MM-dd')}"` |
| 字典字段 | `th:value="${@dict.getLabel('dict_type', xxx.field)}"` |
| 状态字段 | 优先用状态标签（见第 3 节），不用则输出文本 |
| 空值 | 显示 `-` 或空框均可，保持全页一致（推荐空框） |
| 图片/附件 | 用 `.detail-img` + `.img-hint`（见第 4 节） |

---

## 3. 状态标签

**用法**：状态值统一用彩色标签，禁止裸数字。

```html
<span th:if="${xxx.status == 1}" class="tag-wait">待开始</span>
<span th:if="${xxx.status == 2}" class="tag-run">维修中</span>
<span th:if="${xxx.status == 3}" class="tag-ok">已完工</span>
```

| 状态 | 样式类 | 颜色 |
|---|---|---|
| 待开始/等待 | `tag-wait` | 蓝 |
| 进行中 | `tag-run` | 橙 |
| 完成/正常 | `tag-ok`（RuoYi 内置） | 绿 |
| 异常/失败 | `tag-err`（RuoYi 内置） | 红 |

新增状态色需在 `ry-ui-ext.css` 补充并同步本文档，禁止页面内联。

---

## 4. 图片/附件预览

```html
<img class="detail-img" th:src="@{'/profile/' + xxx.img}" alt="图片" onclick="window.open(this.src)">
<div class="img-hint" th:text="${xxx.img}">文件名</div>
```

- 图片限高 320px、圆角、悬停放大指针，点击新窗口查看原图（公共样式 `.detail-img`）。
- 文件名浅灰小字显示在图片下方（`.img-hint`）。
- 空值用 `th:if` 整块隐藏。

---

## 5. 列表页（bootstrap-table）

- 表格列定义放 `columns: [...]`，统一格式：`{ field: 'xxx', title: '名称' }`。
- 操作列放最后，按钮顺序：**浏览 → 编辑 → 删除**（`btn-xs` 小按钮）。
- 字典列用 `formatter` + `$.table.selectDictLabel(datas, value)`，字典数据在页头用 `[[${@dict.getType('xxx')}]]` 获取。
- 工具栏按钮顺序：**添加 → 修改 → 浏览 → 删除 → 导出**。

---

## 6. 按钮样式

| 用途 | 按钮类 |
|---|---|
| 添加 | `btn btn-success` |
| 修改/编辑 | `btn btn-primary` |
| 浏览/详情 | `btn btn-info`（图标 `fa fa-eye`） |
| 删除 | `btn btn-danger` |
| 导出 | `btn btn-warning` |
| 行内操作 | `btn btn-xs`（颜色同上） |

---

## 7. 禁止事项

1. 禁止在页面内 `<style>` 重复定义公共样式类（只读框、标签、图片预览等）。
2. 禁止给按钮/输入框写随意颜色（`style="color:..."`），颜色一律走样式类。
3. 禁止裸状态数字（1/2/3）直接展示，必须映射为标签或文本。
4. 新字段的展示方式若本文档未覆盖，先在 `ry-ui-ext.css` 补充公共类，再更新本文档，最后在页面中使用。

---

## 8. 验收清单（新增/修改页面后自查）

- [ ] 页面引用了 `include :: header` / `footer`，未重复引入公共 CSS
- [ ] 只读框全部 `form-control readonly`，无内联背景色
- [ ] 日期格式 `yyyy-MM-dd`，字典值用 `@dict.getLabel` 或 `selectDictLabel`
- [ ] 状态用 `tag-*` 标签
- [ ] 按钮颜色、顺序符合第 5/6 节
- [ ] 无内联样式（特殊场景已注明原因）
